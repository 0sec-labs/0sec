## Run the CLI

The shortest path is **install → choose model access → authorize a target → review
evidence**. The [quickstart](/getting-started/) covers each step, including runtime
requirements. Default shell execution is on your host, not an OS sandbox.

```bash title="Check your installation before investigating"
0sec --help
0sec doctor
```

In chat, use `/connect` (or `/providers`) for provider authentication, `/model`
for model selection, `/settings` for persisted preferences, and `/resume` for
saved conversations. `/transcript` shows the active conversation; `/history`
opens scan results, not chat history. These local workflows do not imply hosted
signup or a paid inference launch.

## Understand the system

Self-evolution is more than changing a prompt or adding a tool. Keep the mechanism,
activation boundary, and evidence of improvement separate.

| Layer | What to read | Status boundary |
| --- | --- | --- |
| Built-in harness | [Architecture](/architecture/) · [Agent loop](/agent-loop/) | Start with the existing agent and authorized tools. |
| Executable self-evolution | [Plugins and evolution](/improvement-plane/#executable-plugin-evolution) | Versioned executable plugins, source evolution, next-call activation, and rollback are implemented. |
| Live harness replacement | [Driver and UI generations](/improvement-plane/#live-harness-component-contract) | Shared contract and integration work; not an end-to-end qualification claim. |
| Long-horizon optimizer | [Continuity and recovery](/improvement-plane/#long-horizon-self-evolution) | Future optimizer goals are not evidence of measured autonomous improvement. |

## Research and development

[Benchmarks](/benchmark/) and [methodology](/methodology/) describe measured results
and their limits. [Research](/research/) separates design rationale from dated
experiments; the [roadmap](/roadmap/) records planned work. An implementation or a
lifecycle smoke check does not, by itself, establish better security outcomes.

The reference follows the implementation: inspect the
[CLI documentation generator](https://github.com/0sec-labs/0sec/blob/main/scripts/sync-cli-docs.mjs),
the [source repository](https://github.com/0sec-labs/0sec), or this page's source
link below. Hosted inference, managed testing, and CI review have separate access
and accounting; a shared account does not imply shared credits or entitlements.
